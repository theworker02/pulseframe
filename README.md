# pulseframe

Pulse URLs and frame query parts with stable normalization.

**Site:** https://theworker02.github.io/pulseframe/

## Install / run

```bash
git clone https://github.com/theworker02/pulseframe.git
cd pulseframe
node src/cli.js
node --test
```
